# Bidipta Rana: portfolio

Plain HTML, CSS and JavaScript. No build step.

- Text, projects, skills and publications: `js/data.js`
- Photos: `assets/images/<project>/`, videos: `assets/videos/`, reports: `assets/reports/`
- Add your email and GitHub URL in `SITE` at the top of `js/data.js`
- Publish: upload everything inside this folder to a public repo named `<username>.github.io`,
  then Settings > Pages > Deploy from a branch > main / root.
- Share one project directly: `https://<username>.github.io/#p-robotic-finger`
  (ids are listed in `data.js`).
